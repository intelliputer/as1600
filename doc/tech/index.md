# Intellivision Technical Data Repository

This is an archived, offline copy of Joe Zbiciak's Intellivision technical
reference. It covers hardware, electrical interfaces, bus protocols, and
programming. The original web edition described itself as incomplete; the
repository preserves the material available in Release 3.
