# SDK-1600 (Release 3)

A software development kit for General Instrument's CP-1600 family of
16-bit CPUs, most notably the Mattel Intellivision (also marketed by GI as
the GIMINI-8900).

SDK-1600 is independently produced and is not a product of General
Instruments, Mattel Electronics, Intellivision Inc., INTV Corp., or
Intellivision Productions. Its goal is to provide a free—both gratis and
libre—toolset for programming CP-1600-based hardware.

## Contents

- An introduction to the CP-1600 CPU
- The AS1600 CP-1600 assembler and documentation
- The DASM1600 CP-1600 disassembler and documentation
- Utilities for creating, inspecting, and converting ROM and binary images
- Programming examples and library functions
- A mini-EXEC/GROM combination for running examples in an Intellivision
  emulator
- ECScable documentation and source, for communicating between a PC and an
  Intellivision with ECS
- Source code for the complete kit

Prebuilt Linux and Win32 tools are supplied in [`bin/`](bin/). Source and
build instructions are in [`src/`](src/README.txt), and the examples are in
[`examples/`](examples/README.txt).

## Tools

The supplied command-line tools are in `bin/`.

### Code generation

| Tool | Purpose |
| --- | --- |
| `as1600` | Assemble CP-1600 source (the Intellivision CPU) |
| `rom2bin` | Convert Intellicart `.ROM` images to BIN+CFG |
| `bin2rom` | Convert BIN+CFG images to Intellicart `.ROM` |

### Inspection and conversion

| Tool | Purpose |
| --- | --- |
| `show_grom` | Produce ASCII or HTML dumps of `GROM.BIN` |
| `dasm1600` | Disassemble CP-1600 code into reassemblable output |
| `dasm1600o` | Alternate CP-1600 disassembler |
| `dasm0256` | Disassemble SP-0256 speech data |
| `tohex` / `fromhex` | Convert binary files to and from editable hex dumps |
| `tobit` / `frombit` | Convert binary files to and from forward-order bit dumps |
| `tobit_r` / `frombit_r` | Convert binary files to and from reverse-order bit dumps |
| `tobit_f` | Produce the alternate bit-dump format |
| `gms2rom` | Convert INTVPC `.GMS` game saves to `.ROM` |
| `gromfix` | Repair the GROM file generated by `minigrom.asm` |

### Hardware-interface utilities

| Tool | Purpose |
| --- | --- |
| `ec_dump` | Dump EXEC, GROM, and ECS ROMs through ECScable |
| `ec_load` | Load a game through ECScable |
| `ec_test` | Run an ECScable confidence test |
| `ec_watch` | Watch a variable through ECScable |
| `test_cart` | Test a Moeller/Nudds cartridge reader loopback |
| `ivplay` | Play Intellivoice data through a cartridge reader |
| `ivreset` | Reset an Intellivoice attached to a cartridge reader |
| `test_hcif` | Test the INTV2PC hand-controller interface |

Some hardware-focused utilities documented by this release may not be present
in every prebuilt `bin/` distribution.

## Setup

Add the repository's `bin/` directory to your `PATH`, or invoke each tool by
its full path. For example, from a POSIX shell:

```sh
export PATH="$PATH:/path/to/sdk1600/bin"
```

Add that command to your shell's login configuration (such as `~/.profile` or
`~/.bash_profile`) to make it permanent, then start a new shell. Verify the
installation with:

```sh
as1600
```

The expected response when no source file is supplied is `as1600: no input files`.

On DOS or Windows 9x, add the equivalent directory to `C:\\AUTOEXEC.BAT`, for
example:

```bat
PATH=%PATH%;C:\\SDK1600\\BIN
```

Modern Windows users can add the same `bin` directory through their user or
system `PATH` environment variable.

### Building on Linux or Unix

Linux binaries are included, so a build is often unnecessary. To build the
tools yourself, follow [`src/README.txt`](src/README.txt); the resulting
executables are placed in `bin/`.

## Getting started

Read [`QuickStart.txt`](QuickStart.txt) for a guided introduction. The included
programs target the Intellivision and can be used on hardware with an
Intellicart or in a compatible emulator.
